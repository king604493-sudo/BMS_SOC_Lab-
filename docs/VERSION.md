# 版本说明（Version）

## 当前版本：v1.0.0

**发布日期**：2026-10-27

**版本语义**：首个基于真实电芯数据完成算法落地、验证与优化的稳定版本。

### 版本命名规则

采用语义化版本号 `vMAJOR.MINOR.PATCH`：

| 段 | 含义 | 触发条件 |
|---|---|---|
| MAJOR | 主版本 | 算法结构重大变更（如新增模型阶数、更换滤波架构、破坏性 API 变更） |
| MINOR | 次版本 | 新增能力或算法（如新增一个估计器、新增一种离线表） |
| PATCH | 补丁 | 参数修正、bug 修复、文档更新，不改算法结构 |

### v1.0.0 发布范围

本版本在 Codex 交接的 `BMS_SOC_Lab` 基线上，完成了以下工作：

| 模块 | 内容 |
|---|---|
| 数据前置 | 从三星 INR21700-30T 真实数据提取 OCV-SOC 表、HPPC 阻抗、三维阻抗表、容量-温度表 |
| 算法新增 | `Impedance3DLookup`（三维查表）、`run_1rc_ekf_3d`（三维查表 EKF）、`run_dual_ekf_1rc`（双 EKF + 分时门控） |
| 算法修正 | `run_1rc_ekf` 增加 `update_mask`（可选跳更，默认全程更新） |
| 验证 | 25℃ 五个工况（1C/UDDS/LA92/HWFET/US06）全流程标定与误差评估 |
| 结论 | 零阶 R0=6.6mΩ 为最优固定参数；DEKF 在温和工况更优、大电流受浓差极化边界制约 |
